# TechCon

A conference website for the University of Leicester CO1101 class. The site has a home page, a registration form, a three-day schedule, speaker profiles, and a contact form.

This was a group project. I built the website.

## Run it

Open `index.html` in a browser, or use a local server:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## What is included

The pages are `index.html`, `registeration.html`, `schedule.html`, `speakers.html`, `contact.html`, and `style.css`.
